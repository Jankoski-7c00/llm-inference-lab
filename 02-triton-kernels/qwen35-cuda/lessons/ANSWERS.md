# 练习答案与面试口述稿

先闭卷做题，再阅读这里；能识别答案与能独立推导是两件事。

## 第 1 课

无 padding 时分别写 24 个 K 和 V 元素。负 slot 对应 token 不写任何 cache 元素。必须比较整个缓存或状态池，才能发现误写；不能只比较返回的 output。`H=2,HV=4` 时映射为 `[0,0,1,1]`。

三个系统：视觉 encoder 做当前序列的双向 attention；文本 full attention 保存历史 K/V；GDN 将历史压缩进递归矩阵状态。它们的数据结构和访问方式不同。

## 第 2 课

页号 `s/B`，页内位置 `s%B`。`B=4,H=2,D=4,s=7,h=1,d=2` 时偏移为 `((1*4+3)*2+1)*4+2=62`。负 slot 提前跳过；sentinel 区域保持逐元素不变。

随机 slot 能暴露把 token 当 slot、页内偏移错误和跨页错误。重复 slot 对应无序并行写，缺少执行顺序保证，不能定义“最后一个 token 赢”。

## 第 3 课

FP16→FP8 的 K/V 逻辑流量是 `2*T*H*D*2` 读字节加 `2*T*H*D*1` 写字节，再加 metadata。原 dtype FP16 复制是 `8*T*H*D` 字节。有效逻辑带宽只反映该工作量模型；热 L2 下不能直接与显存峰值比较。

`D=33` 存在不完整 pack 与可能不对齐的下一行。保留标量尾部或标量 fallback，不能越界搬运。小 case 的 host launch/提交可能占比高，需对照时间线而非猜测。

## 第 4 课

手算 scale 为 1，INT8 存储为 `[127,1,-1,2,-2,0,-127]`。全零向量的 scale 为 `1e-6`，量化值均为 0。K/V scale 独立，不能使用 K 的最大值量化 V。

scale 是浮点计算结果，存储值是离散编码，反量化误差还乘上 scale；三种判据不能混用。

## 第 5 课

`K=128` 时每条 lane 处理 4 个元素。`K=65` 时部分 lane 处理 3 个，其余处理 2 个，超出部分以 0 参与 absmax。完整 warp 都要参与 full-mask shuffle。

直接 FP32→FP8 RNE 与经过 FP16 的 RTZ/RNE 路径可能在中点两侧产生相邻结果。动态 scale 的除法/reciprocal 路径同样会移动 INT8 半整数边界。先查看自己的 PTX，再决定上游比较判据；本实验 CUDA 与独立数学 reference 的存储仍精确比较。

## 第 6 课

两个序列的 S 是独立的 `2x2` 与 `3x3`，不能形成允许跨序列交互的 `5x5`。当 Q/K 为 0 时每行均匀权重，输出平均 V；第一个 query 也能读取后续 key。避免完整 S/P 写回，是分块融合的切入点。

## 第 7 课

第二个 tile 后 `m=ln(2),alpha=1/2,l=1.5,u=9`，输出为 6。反向处理也得到 `(1*2+2*8)/3=6`。顺序变化只影响浮点累加路径，不改变数学定义。

必须同时重缩放旧分母和旧输出；只更新最大值而不重缩放会混合不同的指数基准。padding query 应避免计算 `-inf-(-inf)`。

## 第 8 课

K tile 的行是 key token、列是 D；转置矩阵的 col-major 地址恰好为 `key*DP+d`，可以直接使用相同物理存储。Q tile 增大同时增加 Q/输出片段、shared memory 和寄存器需求，可能减少并发 CTA。

WMMA fragment 内部 lane 映射不可随意假定。本教学版用 shared memory 交换逐行 softmax 和重缩放数据，易验证但有额外读写。进一步改寄存器版必须明确映射并保留 tail 测试。

## 第 9 课

wait 保证异步拷贝完成；CTA barrier 还保证消费者看到所有生产线程的数据。覆盖 buffer 前要保证上一轮消费者结束。短序列中 commit/wait/barrier 成本可能抵消重叠收益；需要实际测量。

## 第 10 课

正确顺序是：衰减 → 用衰减状态预测 V → 门控残差 → outer-product 更新 → 用更新状态计算输出。手算例子得到 `S=2,o=2`。

状态 `[V,K]` 使矩阵向量乘 `S*k` 产生 V 维预测。K/V 不相等的测试能够发现转置错误。

## 第 11 课

`indices=[6,7,8],accepted=2` 从状态项 7 开始，依次把新状态写到 6、7、8。初始状态先加载到局部 FP32 状态；后来覆盖项 7 不改变已经加载的初值。另一条并行序列写项 7 就会发生竞态。

`inplace=False` 返回每步快照，不应修改初始状态池。索引 0 不可作为正常状态项写入。

## 第 12 课

Qn/Kn 两个 FP32 中间张量各写一次、读一次，合计 `16*T*H*K` 字节；两个 FP32 gate 合计 `16*T*HV` 字节。这里是逻辑流量，缓存与重复读取需另看硬件数据。

直接融合虽然少了两次 launch，却增加了重复 normalization 和门控。单独共享减少重复计算并引入 barrier，实测仍退化；行分块和 K 循环专用化再逐项比较。每一阶段都可能有收益或代价，不能根据减少重复计算就认定更快。代码中的局部数组大小也不能直接等同于最终寄存器数。

## 第 13 课

先确认报告确实含目标 kernel，定位 NVTX 和 stream，再看 kernel 时间及相邻空隙。把现象写成可反驳的假设：例如“直接融合的重复归一化成本抵消了 launch 节省”，修改共享复用后重测。

没有硬件指标时，只能用计时/时间线支持相应结论，不能断言某种 warp stall 或 DRAM 峰值利用率。Compute 补做时使用同一 case、相同初始状态和可比较的运行模式。

## 第 14 课

四段 30 秒概述可参考：

- **Cache**：算子将当前 token 的 K/V 根据 slot mapping 写入分页缓存。我先推导页号、页内偏移和 stride 地址，再完成标量写入；在对齐的 NHD 路径使用向量搬运。正确性检查整个缓存，包括未写区域，性能比较区分小 decode 和较大的 prefill。
- **Dynamic cache**：每个 token/head 独立计算 K/V absmax 和 scale，再完成舍入、饱和与缓存写入。优化用 warp 归约替代单线程扫描。量化的 scale、编码和反量化误差分别验证，并检查实际转换指令带来的边界差异。
- **FA2**：我从明确的非因果 attention 定义出发，用 online softmax 避免完整 S/P 写回，再让 CTA 按 Q tile 并行、warp 分担完整 query 行。随后引入 WMMA 与双缓冲，同时验证变长、尾块和非整齐 dimension。教学版仍保留额外片上通信，需要据报告评估。
- **Delta rule**：算子融合门控、归一化与递归更新，prediction 使用衰减状态，输出使用更新状态。我同时比较输出和状态池，并覆盖 spec 初始索引与非方形状态。实验保留直接融合退化，再逐项检验共享、行分块和 K 专用化。

3 分钟稿按“问题 20 秒 → 契约/公式 40 秒 → 基础实现 30 秒 → 修改 30 秒 → 测试 30 秒 → 自己的实测和边界 30 秒”组织。具体 latency 必须引用自己的结果文件，不背这里未提供的数字。
